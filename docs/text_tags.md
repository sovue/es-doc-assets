# Текстовые теги

Текстовые теги меняют оформление и темп показа реплики. Они записываются прямо в строке, внутри фигурных скобок:

```renpy
label mymod_tags_example:
    me "Это {b}важно{/b}. А это — {i}мысль{/i}."
    me "Подожди{w=0.5}… теперь можно идти."
    return
```

## Оформление текста

У парного тега есть открывающая и закрывающая части. Оформление действует на текст между ними.

| Тег | Пример | Результат |
| --- | --- | --- |
| `{b}…{/b}` | `{b}Внимание{/b}` | Жирный текст |
| `{i}…{/i}` | `{i}Кажется, я здесь уже был.{/i}` | Курсив |
| `{u}…{/u}` | `{u}Название{/u}` | Подчёркивание |
| `{s}…{/s}` | `{s}Неудачный план{/s}` | Зачёркивание |
| `{color=…}…{/color}` | `{color=#ff8800}Закат{/color}` | Цвет в формате HEX |
| `{size=…}…{/size}` | `{size=+8}Громче!{/size}` | Размер относительно текущего; `{size=24}` задаёт размер в пикселях |
| `{cps=…}…{/cps}` | `{cps=10}Медленно…{/cps}` | Скорость появления в символах в секунду |

Теги можно вкладывать друг в друга. Закрывайте их в обратном порядке:

```renpy
me "Обычный текст. {b}Жирный и {color=#ff8800}цветной{/color}{/b}."
```

Для жирного и курсивного текста выбранный шрифт должен поддерживать соответствующее начертание. Если часть реплики оформлена неожиданно, сначала проверьте, закрыты ли теги.

## Паузы в реплике

Эти теги не имеют закрывающей части и используются в диалогах:

| Тег | Что происходит |
| --- | --- |
| `{w}` | Продолжение реплики после нажатия игрока |
| `{w=1.0}` | Пауза на одну секунду, затем продолжение той же реплики |
| `{p}` | Новый абзац после нажатия игрока |
| `{p=1.0}` | Новый абзац после паузы в одну секунду |
| `{nw}` | Переход к следующей команде без ожидания нажатия в конце реплики |
| `{fast}` | Весь текст до этого тега появляется сразу |

```renpy
label mymod_pause_example:
    me "Я хотел спросить{w}… куда мы идём?"
    me "Первая мысль.{p}Вторая мысль, с нового абзаца."
    me "Только не говори, что{nw}"
    show dv angry pioneer
    me "Только не говори, что{fast} ты опять всё забыла!"
    return
```

В последнем примере начало второй реплики повторяется, но благодаря `{fast}` не печатается заново по буквам. Команда `show` выполняется между двумя репликами.

## Скобки, переносы и значения переменных

Перенос строки записывается как `\n`. Чтобы вывести открывающую фигурную скобку, удвойте её: `{{`. Для открывающей квадратной скобки используйте `[[`.

```renpy
me "Первая строка.\nВторая строка."
me "Запись {{b} — это открывающий тег жирного текста."
me "В заметке написано: [[секрет]."
```

Квадратные скобки подставляют значение переменной. Это отдельный механизм, который можно сочетать с тегами:

```renpy
default mymod_score = 3

label mymod_score_example:
    me "У меня {b}[mymod_score]{/b} очка."
    return
```

Если строка приходит от пользователя, например из `renpy.input`, используйте преобразование `!q`, чтобы введённые фигурные скобки не стали текстовыми тегами:

```renpy
label mymod_input_example:
    $ mymod_player_name = renpy.input("Как тебя зовут?").strip()
    me "Привет, [mymod_player_name!q]!"
    return
```

Подробнее: [текст и теги в документации Ren'Py](https://www.renpy.org/doc/html/text.html). Для параметров новых версий движка проверяйте совместимость с версией Ren'Py вашей игры.
