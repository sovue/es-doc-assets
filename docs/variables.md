# Переменные и условия

:::attention
Для лучшего понимания работы переменных и типов данных в Ren'Py рекомендуется **изучить работу переменных в Python 2.7**.
Это не займёт много времени, но поможет в понимании материала.

[Статья на сайте "Учимся с Python"](https://andorei.github.io/learnwithpython.ru2e/ch02.html#index-1).
:::

Если вы хотите, чтобы игра запоминала каждый выбор игрока, то без переменных нам не обойтись.

Объявлять свои переменные можно в любом месте кода игры, и делается это, как с любым Python-кодом, в однострочных блоках `$` или многострочных блоках `python`.  
Синтаксис:

```renpy
    $ <<Название переменной>> = <<Значение переменной>>
```

```renpy
    python:
        <<Название переменной>> = <<Значение переменной>>
```

## Условия

Используя переменные ваш мод может ветвиться, а игрок — выходить на разные концовки.
Для этого существуют условные конструксии с `if`, `elif` и `else` и цикл `while`.

### Блок `if`

Если вам нужно проверить переменную на что-либо, то вам нужен этот блок.  
Синтаксис:

```renpy
    if <<Ваше выражение>>:
        <<Команды при успехе>>
```

Пример:

```renpy
    if route == "dv":
        jump dv_route
```

:::attention
Имейте в виду, что условие будет выполнено, только если ему передано значение истины или выражение, которое выдаёт истину.
:::

:::info
Также имейте в виду, что помимо `jump`, как указано в примерах, можно вставлять целые отрывки повествования.
:::

### Блок `else`

Блок `else` выполнит свои команды, если проверка была провалена.  
Синтаксис:

```renpy
    if <<Ваше выражение>>:
        <<Команды при успехе>>
    else:
        <<Команды при провале>>
```

Пример:

```renpy
    if route == "dv":
        jump dv_route
    else:
        jump other_route
```

### Блок `elif`

Блок `elif` позволяет выполнить дополнительные проверки перед провалом.  
Синтаксис:

```renpy
    if <<Ваше выражение>>:
        <<Команды при успехе>>
    elif <<Другое выражение>>:
        <<Команды при успехе этого условия>>
```

Пример:

```renpy
    if route == "dv":
        jump dv_route
    elif route == "sl":
        jump sl_route
```

:::tip
Дополнительных проверок может быть сколько угодно, и их также можно совмещать с блоком `else`.

Пример:

```renpy
    if route == "dv":
        jump dv_route
    elif route == "sl":
        jump sl_route
    elif route == "un":
        jump un_route
    elif route == "mz":
        jump mz_route
    else:
        jump other_route
```
:::

### Блок `while`

Блок `while` выполняет свои команды пока выражение в его условии равно истине.  
Синтаксис:

```renpy
    while <<Ваше выражение>>:
        <<Команды при успехе>>
```

Пример:

```renpy
    while True:
        "Да здравствует бесконечный цикл!"
```
