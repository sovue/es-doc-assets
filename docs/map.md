# Использование карты

В этой статье вы узнаете, как пользоваться картой.

:::info
Все **работающие** функции карты, как и их назначение и список зон вы сможете найти в [конце статьи](#список-функций-и-локаций).
:::

## Краткое руководство

Перед тем, как показать карту игроку, её нужно настроить.
Для начала вам понадобятся лэйблы, на которые будет переходить игрок.  
Пример:

```renpy
label square_label:
    $ disable_current_zone()
    "Площадь"
    jump showing_map
label beach_label:
    $ disable_current_zone()
    "Пляжный эпизод!"
    jump showing_map
label library_label:
    $ disable_current_zone()
    "Библиотека"
    jump showing_map
```

:::attention
Имейте в виду, что при нажатии на любую зону автоматически она не отключится, и на неё можно будет перейти несколько раз при повторном использовании той же карты.
Чтобы этого не происходило существует функция `disable_current_zone()`.
:::

После этого, до этих лэйблов, карту стоит очистить и добавить на неё нужные зоны.
Для этого используются следующие функции.  
Пример:

```renpy
    $ disable_all_zones()
    $ set_zone("square", "square_label")
    $ set_zone("beach", "beach_label")
    $ set_zone("library", "library_label")
```

И после этого вы можете показать саму карту.  
Пример:

```renpy
label showing_map:
    $ show_map()
```

:::attention
Если вы планируете использовать одну и ту же карту несколько раз, то функцию отображения карты рекомендуется поместить в отдельный лэйбл, **отдельно от функций настройки**.
:::

Для дополнительных проверок можно получить количество посещений последней посещённой локации.
Делается это с помощью функции `been_there()`.  
Пример:

```renpy
label forest:
    if been_there() > 1:
        "Так я же уже был в лесу. Зачем я сюда пришёл?"
        jump showing_map
```

## Список функций и локаций

### Функции

:::table
№;Функция;Назначение
1;`show_map()`;Показывает карту
2;`set_zone(<<Ключ зоны>>, <<Название лэйбла>>)`;Включает зону `<<Ключ зоны>>` и задаёт ей лэйбл `<<Название лэйбла>>`
3;`reset_zone(<<Ключ зоны>>)`;Сбрасывает и деактивирует зону `<<Ключ зоны>>` и сбрасывает её счётчик посещений
4;`disable_current_zone()`;Деактивирует последнюю посещённую зону
5;`disable_all_zones()`;Деактивирует все зоны
6;`been_there()`;Выводит кол-во посещений последней посещённой зоны
:::

Помимо функций выше также сущестуют другие, неработающие.
Мы не стали включать их сюда, чтобы вас не путать.
