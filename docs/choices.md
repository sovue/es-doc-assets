# Выборы

Используя меню читатель может совершать какие-либо выборы во время повествования.
Для этого используется блок `menu`.

К каждому выбору также можно добавить условие его отображения в интерфейсе.

Синтаксис:

```renpy
    # В повествовании...
    menu:
        <<Ваш текст выбора>>:
            <<Ваши команды>>
        <<Ваш текст выбора>> <<Ваше условие>>:
            <<Ваши команды>>
```

Пример:

```renpy
    menu:
        "Пойти налево":
            jump left_path
        "Подождать":
            "Я решил не спешить."
            pause 5.
            "Хватит ждать."
            jump after_wait
        "Открыть дверь ключом" if has_key == True:
            "Точно! Ключи!"
            jump open_door
```
