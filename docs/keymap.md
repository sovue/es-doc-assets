# Привязывание собственных действий к клавишам

Чтобы добавить какие-либо действия, выполняемые при нажатии определённых клавиш, в Ren'Py используются особый класс `renpy.Keymap`.

При добавлении объектов этого класса в список дисплейблов низшего слоя (`config.underlay`) и добавления клавиш в поле `config.keymap` они ловят нажатия на клавиши и выполняют указанные действия.

Пример:
```renpy
init python:
    config.underlay.append(renpy.Keymap(
        my_action = Play("audio", sfx_achievement)
    ))
    config.keymap["my_action"] = ["shift_K_j"]
```

Помимо клавиш клавиатуры в комбинации можно передать и нажатие кнопок мыши.
Для этого используются ключи в формате `mouseup_<<Число>>` или `mousedown_<<Число>>`, где число:
| | |
| --- | --- |
| 1 | Левая кнопка мыши |
| 2 | Средняя кнопка мыши |
| 3 | Правая кнопка мыши |
| 4 | Колёсико вверх |
| 5 | Колёсико вниз |
| 6 | Передняя боковая кнопка мыши |
| 7 | Задняя боковая кнопка мыши |

Также каждой клавише можно дать некоторые модификаторы, которые будут требовать соблюдение некоторых условий.  
Пример использования:

```python
"shift_ctrl_anyrepeat_K_g"
```

:::details Список доступных модификаторов
| Префикс | Что требует |
| ---: | :--- |
| `meta` | Требуется зажать клавишу "META", "COMMAND" или "WINDOWS" |
| `ctrl` | Требуется зажать клавишу "CTRL" |
| `osctrl` | Требуется зажать клавишу "ALT" на компьютерах Macintosh или клавишу "CTRL" в других системах |
| `anymod` | Требуется зажать клавишу "CTRL", "ALT", "META", "COMMAND" или "WINDOWS" |
| `shift` | Требуется зажать клавишу "SHIFT" |
| `noshift` | Требуется не зажимать клавишу "SHIFT" |
| `caps` | Требуется включённый "CAPS LOCK" |
| `nocaps` | Требуется выключенный "CAPS LOCK" |
| `num` | Требуется включённый "NUM LOCK" |
| `nonum` | Требуется выключенный "NUM LOCK" |
| `repeat` | Требуется зажать клавишу |
| `anyrepeat` | Требуется нажать или зажать клавишу |
| `keydown` | Требуется нажать клавишу (стандартный модификатор) |
| `keyup` | Требуется отпустить клавишу |
:::
:::

:::attention
Для большей части привязанных к клавишам действий в игре были использованы экранные действия, но также можно использовать и обычные Python-функции.

Имейте ввиду, что без использования экранного действия `Function` или каррирования функции аргументы передать не получится.
:::
