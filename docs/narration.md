# Построение повествования

В Ren'Py повествованием назвается процесс описания и представления игроку происходящих в сюжете произведения событий. Всё повествование происходит в отдельных Ren'Py блоках, называемых [лэйблами](#лэйблы-35), и в основном состоит из [вывода реплик](#вывод-реплик-133), манипуляций над изображениями, проигрыванием аудио и прочих действий.

```renpy
label day3_main2: # game\scenario\day3.rpy:311
    window show
    "Я дожёвывал сосиску, которая больше напоминала кусок витой пары."
    me "Интересно, есть у них здесь интернет?"
    me "Откуда?"
    "Пионер за соседним столом заметил, что я разговариваю сам с собой, покосился на меня, а я в ответ улыбнулся и помахал ему рукой."
    "После такого дружелюбного приветствия он почему-то быстрыми шагами покинул столовую, даже не доев завтрак."
    stop ambience fadeout 2
    th "С едой покончено – самое время отправиться на поиски разгадок."
    window hide
```

## Лэйблы

**Лэйблы** (или просто **метки**, от англ. *Label*) — это специальная метка, которая позволяет повествованию перемещаться в конкретные места в сюжете.  
Cинтаксис:

```renpy
label |Название лэйбла|:
    |Дальнейшие команды| # Всё дальнейшие команды могут быть написаны без отступа в начале, но мы не рекомендуем этого делать.
```

:::warning
Во избежание конфликтов имя каждого лэйбла должно быть уникальным и отличаться от всех остальных.
В больших модах название лейбла часто состоит из сокращённого названия мода, ключевого слова `label` или `lbl` и названия сцены или номера дня/главы/эпизода/прочего.
Пример:
```
mymod_label_day2
↑     ↑     ↑
│     │     Название сцены
│     Ключевое слово, обозначающее лэйбл
Название мода
```
:::

### Глобальные и локальные лэйблы

Ранее показанные лэйблы являются глобальными, и вызвать их можно из любой части игры.
Но помимо глобальных существуют и локальные лэйблы.
Они всегда принадлежат своему глобальному лэйблу и не могут существовать без него.  
Cинтаксис:

```renpy
label |Название глобального лэйбла|:
    |Команды|
label .|Название локального лэйбла|: # Краткое написание, принадлежит первому найденному глобальному лэйблу
    |Команды|
label |Название глобального лэйбла|.|Название локального лэйбла|: # Полное написание, принадлежит к глобальному лэйблу перед точкой
    |Команды|
```

Если повествование находится в глобальном лэйбле с подконтрольными ему локальными лэйблами, то на них можно перемещаться, используя только названия локального лэйбла.  
Пример:

```renpy
label global_label:
    "Внутри этого глобального лэйбла есть..."
    jump .local_label

label .local_label:
    "...локальный лэйбл!"
```

Также можно переместиться в локальный лэйбл другого глобального лэйбла.
Для этого нужно использовать связку в виде названия глобального лэйбла и названия локального лэйбла, разделённых точкой.  
Пример:

```renpy
label global_label:
    "Мы в глобальном лэйбле."
    jump another_global.local_label

label another_global:
    "Учите английский язык!"

label .local_label:
    "А теперь мы в локальном лэйбле другого глобального лэйбла."
```

### Перемещение между лэйблами

:::info
Далее в статье будет использован такой термин, как **стэк**.

Стэк можно описать как список точек, с которых продолжится повествование после того, как оно дойдёт до команды `return`.
Каждая команда `call` добавляет такую точку после себя, а команда `return` возвращает повествование на последнюю такую точку и удаляет её из стэка.

Если точек в этом списке не осталось и повествование доходит до команды `return`, то игра перезапускается, что создаёт эффект возвращения в главное меню.
:::

Для перемещения между лэйблами существует три команды: `jump`, `call` и `return`.

1. Команда `jump` (от англ. *прыжок*) перемещает повествование в новый лэйбл не обновляя стэк.  
Пример:

```renpy
label start:
    "Начало"
    jump next_label # Перемещаемся в next_label...
    "После прыжка" # До сюда повествование не дойдёт, так как этой точки нет в стэке

label next_label:
    "Следующий лэйбл"
```

2. Команда `call` (от англ. *вызов*) перемещает повествование в новый лэйбл обновляя стэк, что позволяет вернуться в предыдущий лэйбл командой `return`.  
Пример:

```renpy
label start:
    "Начало"
    call next_label # Перемещаемся в next_label...
    "После вызова" # Вместо jump была использована команда call и этот текст будет выведен читателю

label next_label:
    "Следующий лэйбл"
    return # Возвращаем повествование в лэйбл "start"...
```

3. Команда `return` (от англ. *возврат*) удаляет последнюю команду из стэка и возвращает повествование к ней. Если стэк пуст — возвращает игрока в главное меню.  
Пример:

```renpy
label start:
    "Начало"
    call next_label # Перемещаемся в next_label...
    "После вызова"
    return # Стэк пуст! Возвращаем игрока в главное меню...

label next_label:
    "Следующий лэйбл"
    return # Возвращаемся к последнему лэйблу в стэке...
```

:::info
Если перед концом лэйбла не стоит команда `return`, то повествование пойдёт дальше и достигнет следующего лэйбла.
Если же после конца лэйбла нет других лэйблов, то игра закончится, и игрок вернётся в главное меню.  
Пример:

```renpy
label start:
    "Начало"
    # Здесь ничего не осталось, дальше только следующий лэйбл

label next_label:
    "Следующий лэйбл" # А после этой команды ничего нет, и игрока вернёт в главное меню
```
:::

## Вывод реплик

Чтобы вывести какую-либо реплику какого-либо персонажа в повествовании используется внутренняя команда, которая состоит из двух частей: Вызываемого объекта персонажа/имени персонажа строкой и реплики.

```renpy
    "|Реплика|"
    "|Имя персонажа|" "|Реплика|"
    |Вызываемый объект| "|Реплика|"
```

Примеры:

```renpy
    # ...
    "Привет!" # На экран выведется текст "Привет!" без имени персонажа
    "Персонаж" "Привет!" # На экран выведется текст "Привет!" от персонажа "Персонаж"
    sl "Привет!" # На экран выведется текст "Привет!" от Слави
    # ...
```

:::info
Если в команду передана только одна строка текста, то она будет восприниматься как реплика от внутреннего персонажа `narrator` — рассказчика, у которого нет видного игроку имени.

Чаще всего для удобства для каждого персонажа создаётся переменная, в которой и хранится его объект. О том, как создавать новых персонажей, читайте в [этой статье](/docs/characters).

Узнать какие переменные отвечают за каких персонажей можно на [странице с ресурсами оригинальной игры](/resources/original/characters).
:::

## Особые функции повествования

В игре "Бесконечное Лето" имеется несколько особых функций, которые вызываются во время повествования.

### Изменение стиля интерфейса

При использовании стандартного интерфейса новеллы во время повествования можно изменить его стиль. Для этого в повествовании нужно вызвать фунцкию смены интерфейса.

Пример:

```renpy
    # ...
    $ day_time() # Дневной стиль интерфейса
    "Днём было светло."
    $ sunset_time() # Утренний/вечерний стиль
    "Но день подходил к концу."
    $ night_time() # Ночной стиль
    "А ночью было темно."
    $ prolog_time() # Стиль пролога
    "И холодно."
    # ...
```

### Изменение оттенка спрайтов

При использовании стандартных спрайтов новеллы во время повествования можно изменить их оттенок. Для этого в повествовании нужно изменить постоянную переменную "времени спрайтов".

Пример:

```renpy
    # ...
    show sl normal pioneer
    $ persistent.sprite_time = "day" # Дневной оттенок (без оттенка)
    pause
    $ persistent.sprite_time = "sunset" # Утренний/вечерний оттенок
    pause
    $ persistent.sprite_time = "night" # Ночной оттенок
    pause
    # ...
```

> <b style="color: #FFFFFF; background: #0006; border-radius: 8px; padding: 8px">■ Цвет дневного оттенка  #FFFFFF. ■</b>

> <b style="color: #EFD1FF; background: #0006; border-radius: 8px; padding: 8px">■ У утренних/вечерних спрайтов оттенок цвета #EFD1FF. ■</b>

> <b style="color: #A0C6D1; background: #0006; border-radius: 8px; padding: 8px">■ У ночных спрайтов оттенок цвета #A0C6D1. ■</b>

:::warning
Смена оттенка не распространяется на некоторые спрайты оригинальной новеллы и на все пользовательские спрайты!
Их нужно будет красить самому или добавлять проверки как в оригинальной новелле!
Пример покраски спрайта с проверкой можно найти в [файлах скриптов игры](/resource/raw/sprites.rpy).
:::

:::info
**Имейте ввиду!**

Как такового "прологового" оттенка в игре нет, в эпилоге (где используется прологовый стиль интерфейса) использован ночной оттенок.
:::

### Изменение режима повествования

Как вы уже наверное знаете в базовой игре существует два режима вывода текста. Называются они ADV- и NVL-режимами.  
В **ADV-режиме** (от англ. *Adventure* — **Приключение**) одновременно выводится небольшой отрывок текста и могут присутствовать персонажи, эффекты и т.д. **Этот режим всегда включён по умолчанию.**  
В **NVL-режиме** (от англ. *Novel* — **Новелла**) выводится одно большое окно с текстом и фоном.

Пример:

```renpy
    # ...
    $ set_mode_adv() # Ещё раз напоминаем что ADV-режим стоит по умолчанию!
    "Короткая фраза."
    $ set_mode_nvl() # Изменяем на NVL-режим...
    "Lorem ipsum dolor sit amet..." # А здесь уже можно писать длинный текст
    # ...
```

:::warning
**Внимание!**

Смена режимов работает только для ванильных персонажей и не распространяется на пользовательских персонажей!
Список ванильных персонажей можно найти на странице с [ресурсами оригинальной игры](/resources/original/characters).
:::

:::info
**Плавные переходы окон**

Не забывайте про плавные переходы для окон, в которых ведётся повествование.

Для ADV-режима:

- `window hide` — плавное скрытие диалогового окна.
- `window show` — плавное появление диалогового окна.

Для NVL-режима:

- `nvl show dissolve` — плавное появление NVL-окна.
- `nvl hide dissolve` — плавное скрытие NVL-окна.

:::info
**Появление персонажа в NVL-режиме**

Персонажи могут быть объявлены для использования в NVL-режиме путем создания ещё одного персонажа, но с добавлением параметра kind=nvl. Например:


##  Оформление текста

 Примеры текстовых тегов:

1. **alpha**

Текстовый тег `alpha` отображает текст, расположенный между самим тегом и его закрывающим тегом, с указанной непрозрачностью. Непрозрачность должна иметь значение между 0.0 и 1.0, что соответствует полной прозрачности и полной непрозрачности соответственно. Если значение начинается с префикса `+` (добавить на) или `-` (убавить на), непрозрачность будет изменена на указанное число, а не полностью заменена. Если значение начинается с префикса `*` (умножить на), непрозрачность будет умножена на это число.

```renpy
"{alpha=0.1}Этот текст едва читаем!{/alpha}"
"{alpha=-0.1}Этот текст на 10 процентов прозрачнее, чем текст по умолчанию.{/alpha}"
"{alpha=*0.5}Этот текст наполовину такой же непрозрачный, как и по умолчанию.{/alpha}"
```

2. **b** (bold)

Тег жирного шрифта выводит текст, расположенный между самим тегом и его закрывающим тегом, жирным шрифтом.

```renpy
"Пример {b}текста, выделенного жирным шрифтом{/b}."
```

3. **color**

Текстовый тег `color` отображает текст, расположенный между самим тегом и его закрывающим тегом, в указанном цвете. Цвет должен быть в формате #rgb, #rgba, #rrggbb или #rrggbbaa.

```renpy
"{color=#f00}Красный{/color}, {color=#00ff00}Зелёный{/color}, {color=#0000ffff}Синий{/color}"
```

4. **i** (italic)

Тег курсива отображает текст, расположенный между самим тегом и его закрывающим тегом, курсивом.

```renpy
mt "Добро пожаловать в {i}СОЛ «Совёнок»!{/i}."
```

5. **s** (strikethrough)

Тег зачеркивания проводит черту через текст, расположенный между тегом и его закрывающим тегом.

```renpy
mi "Я очень надеюсь, что {s}тебе понравилось{/s}."
```

6. **u** (underline)

Тег подчеркивания подчеркивает текст, расположенный между самим тегом и его закрывающим тегом.

```renpy
mi "Рада видеть {u}тебя{/u}!"
```

7. **w** (wait)

Тег ожидание – самозакрывающийся тег, который ждёт, пока читатель нажмёт на кнопку для продолжения. Если для тега задан аргумент в форме числа, то ожидание автоматически заканчивается, когда заданные секунды проходят.

```renpy
un "Я{w} очень{w=1.0} рада!"
```

Полный список текстовых тегов можно найти внутри [соответствующей статьи в документации Ren'Py](http://ru.renpypedia.shoutwiki.com/wiki/%D0%A2%D0%B5%D0%BA%D1%81%D1%82_(Text)).
