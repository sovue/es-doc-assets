## Создание своих персонажей

Чтобы создать своего персонажа достаточно создать новую переменную и вызывать её в повествовании.
Для создания персонажа используется функция^1 `Character`.  
Синтаксис:

```renpy
init: # При инициализации...
    $ |Название переменной| = Character("|Имя персонажа|", kind=|Родительский персонаж|, |Прочие аргументы|)
```

```renpy
    # В повествовании...
    |Название переменной| "|Реплика персонажа|"
    # ...
```

Если у персонажа есть свой родитель^2, то он будет наследовать его свойства.
Чаще всего это называется **наследованием**.  
Пример:

```renpy
init:
    $ test_char = Character("Пример", kind=sl)
```

Персонаж в примере позаимствует от `sl` (Слави) цвет имени и стиль текста реплики^3, но имя у него будет новое — "Пример".

:::tip
Если вы хотите наследовать оригинальный стиль реплики и иметь возможность быстро менять режим повествования, то рекомендуется всегда наследоваться от ванильных^4 персонажей (лучше всего от `narrator`).
:::

### Персонаж-шаблон

Используя наследование можно создать **шаблон персонажа**, который можно будет использовать для создания других персонажей со свойствами одного общего родителя.  
Пример:

```renpy
init:
    $ template = Character(None, what_color="#F00", what_underline=True, what_bold=True) # Родительский персонаж
    $ test_char = Character("Пример", kind=template) # Дочерние персонажи
    $ test_char_2 = Character("Пример 2", kind=template)
```

Реплики персонажей `test_char` и `test_char_2` в примере будут <span style="color: #f00;">красными</span>, <u>подчёркнутыми</u> и **полужирными**, не смотря на то, что имеют разные имена.

### NVL-персонаж

Наследуйте вашего персонажа от `nvl`, если хотите чтобы ваш персонаж использовал экран NVL для вывода реплик.
При этом если наследоваться от любого ванильного персонажа (лучше всего от `narrator`), то менять режим повествования можно так же, как и для ванильных персонажей, с помощью `$ set_mode_nvl()`.

```renpy
init:
    $ test_char = Character("Пример", kind=narrator)
```

```renpy
    # ...
    test_char "Здесь будет обычная реплика."
    $ set_mode_nvl()
    test_char "А здесь - реплика в NVL-режиме."
    # ...
```

## Свойства персонажа

:::attention
Здесь будут рассматриваться самые часто используемые свойства которые можно применить к персонажу.
Полный список смотрите на [странице официальной документации Ren'Py](https://www.renpy.org/doc/html/dialogue.html#Character).
:::

### Префиксы и постфиксы имени и реплик

Аргументы `who_prefix`, `who_suffix`, `what_prefix` и `what_suffix` позволяют добавлять текст в начале и конце имени и реплик персонажа.  
Пример:

```renpy
init:
    $ test_char = Character("Пример", who_prefix="1", who_suffix="2", what_prefix="3", what_suffix="4")
```

Персонаж в примере будет иметь цифру "1" перед именем, "2" после имени, "3" перед репликами и "4" после реплик.

### Свойства стиля

Прочие аргументы функции Character, начинающиеся с `who_`, `what_` и `window_`, очищаются от префикса и используются для применения свойств стиля к тексту имени, тексту реплик и окну соответственно.  
Пример:

```renpy
init:
    $ test_char = Character("Пример", who_color="#F00", what_underline=True)
```

Персонаж в примере будет иметь полностью <span style="color: #f00;">красный цвет</span> имени, а текст реплик будет <u>подчёркнут</u>.

Таким же образом к тексту имени, тексту реплик или окну можно применить целые стили.  
Пример:

```renpy
init:
    $ test_char = Character("Пример", who_style="my_style")
```

Также как персонажей можно использовать простые функции, которые уже будут обращаться к другим персонажам.
Она принимает аргументы в виде самой реплики (`what`) и прочих именованных аргументов (`kwargs`).  
Пример:

```renpy
init python:
    def test_func_char(what, **kwargs):
        if len(what) % 2 == 0: # Если в реплике чётное число символов...
            narrator(what, **kwargs) # Говорит "narrator" - рассказчик
        else: # Если нет...
            th(what, **kwargs) # Говорит "th" - мысли ГГ
```

```renpy
    # ...
    test_func_char "Чётное" # Скажет рассказчик
    test_func_char "Не чётное" # Скажут мысли ГГ
    # ...             ↑ Пробел считается за символ
```

Сам по себе персонаж — это объект, метод `__call__` которого принимает аргументы в виде реплики и прочих именованных аргументов.
Зная это, открывается огромный простор для экспериментов над контролем над выводом реплик.
