# es-doc-assets

Контент и данные для сайта документации по моддингу «Бесконечного лета»
(*Everlasting Summer*): статьи, каталог ресурсов игры, списки художников,
учебных материалов и новостных площадок.

## Серверная конфигурация

`config.yaml` — конфигурация самого сайта. Она хранится в этом репозитории,
чтобы тексты баннеров, названия их состояний, сообщения об ошибках и ссылки
поддержки менялись вместе с контентом. Пути к локальным каталогам и кэшу в неё
не входят: их задаёт `.env` в репозитории приложения `es-doc`.

## Деплой

После push в `main` GitHub Actions подключается к серверу по SSH, пересобирает
контейнер `web` из Git-копии приложения `es-doc` с `ASSETS_REF`, равным SHA
этого push, и ждёт успешного health check. Отдельный Git-клон `es-doc-assets`
на сервере не нужен: Dockerfile приложения загружает содержимое во время
сборки.

В GitHub Environment `production` этого репозитория нужны secrets
`DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_PATH`, `DEPLOY_SSH_KEY` и
`DEPLOY_KNOWN_HOSTS` — те же значения, что используются в `es-doc`.
`DEPLOY_PATH` указывает на Git-копию **приложения** с `compose.production.yaml`
и `.env.production`. Если в окружении включено обязательное одобрение,
GitHub приостановит деплой до него.

## Ресурсы сообщества

Чтобы добавить ресурс, положите файл в папку категории внутри `community/`.
Для изображений доступны `images/bg`, `images/cg`, `images/anim`,
`images/sprites` (или короткие `bg`, `cg`, `anim`, `sprites`); для звука —
`sound/music`, `sound/ambience`, `sound/sfx` (или `music`, `ambience`, `sfx`).
Внутри них можно создавать вложенные папки. Изображения: JPG, PNG, WebP, GIF.
Аудио: OGG, MP3, WAV, Opus. Каталог обновляется по файлам, объявления Ren'Py
не нужны.

Подписи добавляются в `community-descriptions.yaml` по пути относительно
`community/`:

```yaml
sound/ambience/cave.ogg:
  title: 'Пещера'
  description: 'Фоновая музыка для подземных сцен.'
  captions:
    - 'Автор: Имя автора'
    - 'Лицензия: CC BY 4.0'
```

Все поля необязательны. Если у музыкального файла нет `title`, плеер покажет
путь `/resource/community/sound/ambience/cave.ogg`. `descriptions.yaml` и
`game/resources.rpy` по-прежнему относятся только к ресурсам игры.

## Лицензии

В репозитории соседствуют материалы с **разными** правовыми режимами. Читайте
внимательно перед тем, как что-либо переиспользовать.

Ресурсы игры «Бесконечное лето» принадлежат **Soviet Games** и распространяются
на условиях Creative Commons Attribution-NonCommercial-ShareAlike. GPL на них
**не распространяется**, подробности и условия в [`NOTICE.md`](NOTICE.md).
